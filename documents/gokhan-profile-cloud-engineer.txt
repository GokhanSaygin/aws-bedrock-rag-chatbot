Cloud Database Migration Experience:
At UNIVERA, Ahmet supported an on-premises Oracle database migration to Amazon RDS. He used AWS Schema Conversion Tool (AWS SCT) to assess and convert database schemas and AWS Database Migration Service (AWS DMS) to perform the full data load and ongoing Change Data Capture (CDC). The environment used a site-to-site VPN for secure connectivity, Amazon S3 for staging, and Amazon CloudWatch for monitoring. During cutover, the source database was placed in read-only mode, DMS replication lag was verified, and application connectivity was validated before traffic was switched. After migration, Ahmet used Amazon RDS Performance Insights and CloudWatch to investigate high CPU and latency, then supported query and index optimization.
